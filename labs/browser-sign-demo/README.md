# Demo: браузерная подпись (заготовка)

Учебная страница для дня 17 и трека B мини-проекта.

## Требования

- Windows  
- КриптоПро CSP  
- КриптоПро ЭЦП Browser plug-in + расширение браузера  
- Открытие страницы способом, рекомендованным вендором (часто HTTPS или специальные условия для file/localhost)

## Как использовать

1. Установите стек плагина (день 16).  
2. Откройте `index.html` в поддерживаемом браузере.  
3. Дождитесь инициализации плагина.  
4. Нажмите «Показать сертификаты», затем «Подписать».  

## Важно

- Это учебный каркас: API `cadesplugin` / CADESCOM может отличаться по версии — сверяйте с актуальными примерами КриптоПро и при необходимости поправьте вызовы в `sign.js`.  
- Не используйте на боевых документах без ревью безопасности (день 20).
