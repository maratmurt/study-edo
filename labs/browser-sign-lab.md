# Лаба — подписать → проверить → сломать → починить

**Когда:** день 21 (подготовка — дни 16–17).

## Цель

Закрепить отладку браузерной подписи на трёх искусственных поломках.

## Часть A — happy-path

1. Убедитесь, что CSP + plug-in + расширение установлены (паспорт версий).  
2. Подпишите строку или файл (demo / sample КриптоПро).  
3. Проверьте подпись инструментом КриптоПро.  
4. Сохраните в журнал: thumbprint, режим (detached/attached), результат проверки.

## Часть B — три поломки

Выполните **три** сценария из списка (или свои эквивалентные):

| # | Поломка | Ожидаемый симптом | Фикс |
|---|---------|-------------------|------|
| 1 | Выключить расширение браузера | Плагин не найден | Включить + reload |
| 2 | Изменить 1 символ данных после подписи | Проверка fail | Вернуть байты / переподписать |
| 3 | Вынуть токен (если ключ на токене) | Ошибка носителя / нет ключа | Вставить токен |
| 4 | Открыть страницу по `http://` (не localhost) | Init fail / блокировка | HTTPS |
| 5 | Incognito без разрешения расширения | Плагин не найден | Разрешить / обычное окно |

Для каждого: время до гипотезы, время до фикса, скрин/текст ошибки.

## Часть C — бумажный вариант (без стенда)

Для поломок 1–5 опишите симптом, слой архитектуры (день 15), первые 3 проверки и фикс — без выполнения на ПК.

## Критерий сдачи

- [ ] Happy-path или бумажный эквивалент  
- [ ] 3 поломки задокументированы  
- [ ] Обновлена шпаргалка недели 3
