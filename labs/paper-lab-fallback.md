# Лаборатория на бумаге — когда нет стенда

Используйте, если нет КриптоПро / Диадок / 1С.

## Общие правила

1. Все схемы и playbook’и пишите в `journal/`.  
2. В чеклисте дня отмечайте «бумажный вариант».  
3. Как только стенд появится — перепройдите практические дни 03, 05, 11–12, 16–17, 21.

## Замены по темам

| Тема | Вместо стенда |
|------|----------------|
| Контейнер / CSP | Схемы + разбор скриншотов из доки вендора |
| Подпись файла | Описание команд/GUI + кейс «изменили файл» |
| Диадок UI | Сценарии по справке + таблица статусов |
| API | Таблица методов из OpenAPI |
| 1С | Карта настроек по ИТС / инструкции модуля |
| Плагин | Runbook установки + разбор sample-кода |

## Мини-набор артефактов «вместо кликов»

- sequence diagram подписи;  
- 1 playbook;  
- 1 ответ пользователю;  
- 1 список id для тикета.
