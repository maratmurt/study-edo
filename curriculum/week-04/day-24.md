# День 24 — Сопровождение: обновления и истечение сертификатов

**Время:** 1,5–2,5 ч  
**Цель дня:** календарь сопровождения + runbook «сертификат истекает через 14 дней».

## Теория

### Что сопровождать регулярно

| Объект | Риск устаревания | Типичный период внимания |
|--------|------------------|--------------------------|
| Сертификаты КЭП | Внезапный отказ подписи | За 30/14/7 дней до expiry |
| МЧД | Отказ по полномочиям | Срок доверенности + отзывы |
| КриптоПро CSP | Несовместимость с ОС/браузером | После патчей Windows / раз в квартал |
| Browser plugin + расширение | «Не видит плагин» | Вместе с CSP / Chrome major |
| Модуль ЭДО / библиотека 1С | Ошибки форматов, API | Релизы 1С и оператора |
| Корневые/промежуточные УЦ | Цепочка не строится | При смене УЦ / переиздании |
| Драйверы токенов | Носитель не виден | После обновлений Windows |

### Миграция носителей

Смена токена / перевыпуск:

1. Новый сертификат + контейнер.  
2. Назначение в 1С / веб.  
3. МЧД на нового подписанта (если нужно).  
4. Тестовая подпись и тестовый документ.  
5. Отзыв/архив старого доступа по регламенту.  
6. Обновление документации «кто подписывает».

### Коммуникация

За 14 дней: письмо владельцу ключа и админу ЭДО.  
За 7 дней: повтор + тест стенда.  
В день X: контроль, что продление прошло; иначе — план деградации (кто запасной подписант).

## Практика

1. Составьте **календарь сопровождения** на квартал (таблица в журнале): еженедельные/ежемесячные проверки.  
2. Напишите runbook [`support-playbooks/cert-expiry-14d.md`](../../support-playbooks/cert-expiry-14d.md):  
   - обнаружение (как узнать срок);  
   - уведомления;  
   - перевыпуск;  
   - замена в 1С/Диадок;  
   - контрольный тест;  
   - откат.  
3. Добавьте чеклист миграции токена (10 шагов).
