# День 21 — Ретроспектива недели 3: лаба «сломать / починить»

**Время:** 1,5–2,5 ч  
**Цель дня:** пройти лабу подписи end-to-end; закрепить отладку.

## Теория (сжатое повторение)

Слои: страница → JS API → расширение → native/plugin → CSP → носитель → (сервер проверки).  
Формат: чаще CAdES detached.  
Инфра: версии, HTTPS, RDP, токен.  
Безопасность: XSS и фишинг опаснее «слабого пароля на сайте».

## Практика

Выполните [`labs/browser-sign-lab.md`](../../labs/browser-sign-lab.md):

1. **Подписать** тестовые данные.  
2. **Проверить** подпись.  
3. **Сломать тремя способами** (выберите из списка лабы: выключить расширение, изменить данные, вынуть токен, открыть HTTP вместо HTTPS и т.д.).  
4. **Починить** каждый сценарий; зафиксируйте время диагностики.  
5. Дополните [`cheatsheets/week-03-browser-sign.md`](../../cheatsheets/week-03-browser-sign.md).

### Без стенда

Пройдите «бумажную» секцию лабы: для каждого способа поломки опишите ожидаемый симптом и фикс.

## Чеклист «Готово»

- [ ] Могу объяснить отличие поломки плагина от поломки CSP
