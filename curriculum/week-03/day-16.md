# День 16 — Установка КриптоПро Browser Plugin

**Время:** 1,5–2,5 ч  
**Цель дня:** чистая установка связки расширение+плагин; проверка `cadesplugin`; фиксация версий.

## Теория

### Компоненты установки

Обычно нужно **несколько** частей:

1. **КриптоПро CSP** (уже с недели 1).  
2. **КриптоПро ЭЦП Browser plug-in** (native-часть).  
3. **Расширение браузера** (Chrome / YaBrowser / Edge / Firefox — своё).  
4. Иногда — корневые сертификаты УЦ, драйвер токена.

Пропуск любого пункта даёт «страница не видит плагин».

### HTTPS и политики

- Многие сценарии требуют **HTTPS** (или localhost).  
- Корпоративные политики могут запрещать расширения.  
- В Incognito расширения по умолчанию выключены.  
- Несколько профилей браузера = разные наборы расширений.

### Проверка живости

Типичная проверка на странице:

- объект `cadesplugin` доступен после инициализации;
- `cadesplugin.get_plugin()` / проверка версии (API зависит от версии — смотрите актуальную доку и sample);
- список сертификатов не пуст (если ключи установлены).

Зафиксируйте **точные версии** в паспорте рабочего места — это экономит часы при эскалации.

## Практика

### Вариант A — установка на учебном ПК

1. Зафиксируйте baseline: ОС, браузер+версия, CSP версия.  
2. Установите Browser plug-in по инструкции КриптоПро.  
3. Установите расширение из магазина браузера (официальное).  
4. Перезапустите браузер; откройте тестовую страницу КриптоПро / sample.  
5. В журнале запишите:
   - версии CSP, плагина, расширения;
   - видит ли страница плагин (да/нет + текст ошибки);
   - список сертификатов (количество, без секретов).  
6. Проверьте Incognito: работает ли? Зафиксируйте.

### Вариант B — без возможности установить

1. Составьте **runbook установки** на 1 страницу для пользователя L1.  
2. Добавьте раздел «после установки не видно» — 10 проверок.  
3. Опишите, какие скриншоты запросить (версии, chrome://extensions, окно КриптоПро).

Используйте черновик: [`support-playbooks/browser-plugin.md`](../../support-playbooks/browser-plugin.md).
