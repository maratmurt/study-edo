# День 05 — Форматы подписи: CMS и CAdES

**Время:** 1,5–2,5 ч  
**Цель дня:** различать attached/detached и уровни CAdES; подписать и проверить файл (или разобрать формат на бумаге).

## Теория

### CMS (PKCS#7)

**CMS** (Cryptographic Message Syntax) — контейнер, в котором лежат:

- данные (опционально);
- подпись (одна или несколько);
- сертификаты подписантов (часто);
- атрибуты подписи (время, тип контента…).

В Windows/КриптоПро результат часто имеет расширение `.sig`, `.p7s`, `.sgn` — по сути CMS.

### Attached vs detached

| Режим | Данные внутри CMS? | Как хранить документ |
|-------|--------------------|----------------------|
| **Attached** (присоединённая) | Да | Один файл: и документ, и подпись |
| **Detached** (отсоединённая) | Нет | Два файла: `doc.pdf` + `doc.pdf.sig` |

В ЭДО чаще **detached**: документ остаётся читаемым XML/PDF, подпись рядом или в метаданных оператора.

Проверка detached: нужны **оба** файла. Подменили документ — хеш не совпадёт, подпись невалидна.

### CAdES — профили «для жизни»

**CAdES** — набор профилей поверх CMS (ETSI), принятых и в российском контуре с ГОСТ.

| Профиль | Что добавляет | Зачем |
|---------|---------------|--------|
| **CAdES-BES** | Базовая подпись + подписанные атрибуты | Минимум для многих обменов |
| **CAdES-T** | Метка времени (timestamp) | Доказать, что подпись была до истечения сертификата |
| **CAdES-X Long / XLT1** | Доказательства проверки / архив | Долгосрочное хранение |

Для саппорта: если контрагент/ФНС требует «подпись с меткой времени», BES может быть недостаточно.

### Типичные ошибки формата

1. Прислали только `.sig` без исходного файла (detached).  
2. Перекодировали XML (сменили перевод строк / кодировку) после подписи.  
3. Проверяют RSA-инструментом ГОСТ-подпись.  
4. Путают подпись файла и подпись «внутри» формата УПД (структурная).

## Практика

### Вариант A — cryptcp / инструменты КриптоПро

1. Создайте текстовый файл `labs/sample.txt` с произвольным текстом.  
2. Подпишите его **отсоединённой** подписью (через КриптоПро CSP GUI «Подписать» или утилиту `cryptcp` — синтаксис зависит от версии; смотрите `cheatsheets/cryptopro-cli.md`).  
3. Проверьте подпись.  
4. Измените один символ в `sample.txt` и снова проверьте — зафиксируйте результат в журнале.  
5. По возможности создайте attached-подпись и сравните размер/наличие исходного текста внутри.

### Вариант B — без ключа

1. В журнале опишите разницу attached/detached своими словами + схема хранения для УПД.  
2. Заполните: «пользователь прислал только .sig — что запросить?»  
3. Прочитайте шпаргалку [`cheatsheets/signature-formats.md`](../../cheatsheets/signature-formats.md).
