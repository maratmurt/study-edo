# День 09 — Оператор ЭДО, роуминг и приглашения

**Время:** 1,5–2,5 ч  
**Цель дня:** понять роль Диадок как оператора; разобрать организацию, ящик, контрагента и роуминг.

## Теория

### Зачем оператор

Оператор ЭДО:

- идентифицирует участников (организация ↔ ящик ЭДО);
- фиксирует факты отправки/доставки;
- обеспечивает юридическую значимость обмена;
- даёт API и интеграции (1С, учётные системы);
- организует **роуминг** с другими операторами.

Без оператора стороны могут обменяться файлами по email, но это другой уровень доказательности и автоматизации.

### Базовые сущности Диадок (концептуально)

| Сущность | Смысл |
|----------|--------|
| **Организация** | Юрлицо / ИП в кабинете |
| **Ящик (Box)** | Адрес ЭДО организации (идентификатор для обмена) |
| **Сотрудник / пользователь** | Доступ в веб/API, права |
| **Контрагент** | Организация, с которой установлен обмен |
| **Приглашение (invitation)** | Запрос на установление связи с контрагентом |
| **Документ / сообщение** | Единица обмена + подписи + служебные титулы |

Точные названия в UI и API могут отличаться — важна модель.

### Роуминг

Если у вас Диадок, а у контрагента другой оператор:

1. Нужен установленный роуминг между операторами (или через технологию роуминга).  
2. Приглашение/сопоставление ящиков может занимать время и падать из‑за неверных реквизитов.  
3. Ошибки «контрагент не найден» часто про **идентификатор ЭДО / ИНН+КПП**, а не про подпись.

### Приглашения контрагентов

Типичный happy-path:

```text
Найти контрагента (ИНН/КПП / id ящика)
  → Отправить приглашение
  → Контрагент принимает
  → Можно слать документы
```

Сбои: уже есть связь; отказ; неверный КПП обособки; дубли ящиков; роуминг ещё не готов.

## Практика

### Вариант A — есть кабинет Диадок (тест/бой)

1. Найдите в UI: организацию, ящик (id), список контрагентов, раздел приглашений.  
2. Выпишите в журнал идентификатор ящика и 2–3 статуса приглашений/контрагентов (как названы в UI).  
3. Пройдите справку «как пригласить контрагента» и составьте чеклист из 6 шагов своими словами.

### Вариант B — нет кабинета

1. Откройте публичную документацию Диадок для разработчиков / справку (ссылки ниже).  
2. Выпишите определения: Organization, BoxId, Counteragent, Invitation (или русские аналоги из справки).  
3. Нарисуйте схему: две организации на разных операторах + роуминг.  
4. Напишите ответ пользователю: «Почему я не вижу контрагента в списке, хотя ИНН верный?»
