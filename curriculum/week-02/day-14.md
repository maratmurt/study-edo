# День 14 — Ретроспектива недели 2

**Время:** 1,5–2,5 ч  
**Цель дня:** собрать шпаргалку «Диадок + 1С» и одну схему интеграции.

## Теория (сжатое повторение)

```text
1С: документ учёта
  → эл. документ (формат)
  → КЭП (+ МЧД при необходимости)
  → Диадок API / модуль
  → ящик → (роуминг) → ящик контрагента
  → ответная подпись / отказ / завершение
```

Классы сбоев: крипто · идентификация ЭДО · полномочия · формат · интеграция · сеть.

## Практика

### 1. Шпаргалка

Дополните [`cheatsheets/week-02-diadoc-1c.md`](../../cheatsheets/week-02-diadoc-1c.md) своими путями меню 1С и названиями статусов Диадок.

### 2. Одна картинка

В журнале (`journal/day-14.md`) нарисуйте схему интеграции (mermaid или ASCII):

- пользователь;
- 1С;
- CSP;
- Диадок;
- контрагент;
- УЦ (выдача сертификата, не каждый обмен).

Подпишите 2–3 типичные точки отказа на стрелках.

### 3. Ролевая игра

Напишите ответы L1 на реплики:

1. «УПД не дошёл, срочно!»  
2. «В Диадок вижу, в 1С пусто.»  
3. «Сертификат новый, а подпись не принимается.»  
4. «Контрагент на другом операторе.»  

### 4. Самопроверка (да/нет)

1. Роуминг настраивается только сертификатом.  
2. Отсутствие входящих в 1С всегда значит, что оператор не доставил.  
3. МЧД относится к классу «полномочия».  
4. Happy-path УПД можно завершить без ответной подписи получателя, если документ двусторонний.  
5. BoxId нужно сверять между 1С и кабинетом.

*(Ответы: 1 нет; 2 нет; 3 да; 4 обычно нет; 5 да.)*
