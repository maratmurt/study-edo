# День 10 — Диадок API: точки интеграции

**Время:** 1,5–2,5 ч  
**Цель дня:** знать карту API, нужную поддержке и разработке; составить список методов/операций «первой линии».

## Теория

### Зачем API саппорту

Даже если вы не пишете код каждый день, тикеты звучат так:

- «1С не получает документы»;
- «статус не обновляется»;
- «ошибка авторизации в модуле»;
- «webhook не доходит».

Понимание слоёв API помогает понять, **на каком запросе** ломается цепочка.

### Типовые зоны API Диадок

| Зона | Зачем |
|------|--------|
| **Аутентификация** | Токен/логин интеграции, права пользователя API |
| **Организации и ящики** | Узнать BoxId, проверить доступ |
| **Контрагенты / приглашения** | Состояние связи перед отправкой |
| **Отправка документов** | Загрузка файла, подпись, Send |
| **Чтение входящих / событий** | Inbox, лента событий, пометка прочитанного |
| **Печатные формы / генерация** | Иногда отдельный контур |
| **МЧД / полномочия** | Современный обязательный слой для многих сценариев |

Точные имена методов смотрите в актуальной OpenAPI/SDK — вендор обновляет API. Вам нужна **карта зон**, а не заучивание устаревших URL.

### Модели интеграции

```text
1С (или ваш сервис)
    ←→ Диадок API (HTTPS)
            ←→ ящик организации
                    ←→ роуминг / контрагент
```

Авторизация: часто OpenID / токен интегратора + контекст пользователя/организации. Ошибка 401/403 — сначала права и срок токена, не «подпись сломана».

### Что важно логировать при разработке

- correlation id / message id документа;  
- BoxId отправителя и получателя;  
- этап: auth → upload → sign → send → get events;  
- тело ошибки API (код + message), без секретов.

## Практика

### Вариант A — есть тестовый доступ API

1. Оформите/используйте тестовый доступ по инструкции developer.kontur.ru.  
2. Выполните минимальный сценарий из доки: авторизация → список организаций/ящиков.  
3. Зафиксируйте в журнале: как называется метод получения ящиков; где лежит token.

### Вариант B — без доступа (основной для многих)

1. Откройте [документацию Diadoc API](https://developer.kontur.ru/doc/diadoc-api).  
2. Составьте таблицу в журнале (минимум 10 строк):

| Задача поддержки/разработки | Зона API | Пример операции из доки (название) |
|----------------------------|----------|-------------------------------------|
| Не логинится модуль | Auth | |
| Неверный ящик | Organizations/Boxes | |
| Контрагент «не найден» | Counteragents | |
| Документ не уходит | Send / PostMessage | |
| Не видим входящие | Events / Documents | |
| … | | |

3. Выпишите 5 ошибок API (коды/тексты из доки или форума), которые будете узнавать с первого взгляда.

## Чеклист «Готово»
