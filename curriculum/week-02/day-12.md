# День 12 — 1С: библиотека ЭДО и настройки Диадок

**Время:** 1,5–2,5 ч  
**Цель дня:** знать, где в 1С живут настройки обмена, сертификат и идентификаторы; уметь провести первичный осмотр базы.

## Теория

### Как 1С участвует в ЭДО

Типовая картина (конфигурации вроде БП, УТ, ERP + библиотека ЭДО / модуль оператора):

```text
Документ учёта (Реализация, УПД…)
    → подсистема ЭДО формирует электронный документ
    → подпись через криптографию платформы / внешнюю компоненту
    → транспорт к оператору (Диадок)
    → регламентные задания забирают статусы и входящие
```

Важно: **подпись выполняется там, где настроены сертификаты** — на клиенте пользователя или на сервере 1С. От этого зависят требования к CSP на машине.

### Что искать в настройках (чеклист осмотра)

1. **Учётная запись ЭДО / профиль оператора** — организация подключена?  
2. **Идентификатор ЭДО (ящик)** — совпадает с кабинетом Диадок?  
3. **Сертификаты** — назначены ответственным; не просрочены; есть доступ к ключу у того, кто подписывает.  
4. **Регламентные задания** — обмен включён, нет «зависших» ошибок.  
5. **Сопоставление номенклатуры / контрагентов** — для формализованных документов.  
6. **Версия модуля/библиотеки ЭДО** — совместимость с платформой и оператором.  
7. **МЧД** — подключены ли доверенности для подписантов.

Названия форм зависят от конфигурации и версии — ориентируйтесь на смысл пунктов, ищите по словам «ЭДО», «Диадок», «электронные документы».

### Частые точки путаницы

| Наблюдение | Пояснение |
|------------|-----------|
| В вебе Диадок документ есть, в 1С нет | Обмен/регламент / фильтр / другая организация |
| В 1С «отправлен», у контрагента пусто | Роуминг, ящик, задержка, ошибка после отправки |
| Подписывает не тот пользователь | Сертификат привязан к другому сотруднику |
| Работает у админа, не у менеджера | Права 1С + личные сертификаты Windows |

## Практика

### Вариант A — есть база 1С с ЭДО

1. Найдите настройки ЭДО / Диадок; выпишите путь меню в журнал.  
2. Зафиксируйте: идентификатор организации/ящика; способ подписи (клиент/сервер); список сертификатов.  
3. Найдите журнал электронных документов / состояние ЭДО — откройте 1 документ и перепишите статусы.  
4. Проверьте, есть ли регламентное задание обмена и время последнего успешного запуска.

### Вариант B — нет базы

1. По документации 1С (ИТС) / инструкции модуля Диадок для 1С составьте **карту настроек**: список экранов и что на каждом проверить.  
2. Напишите чеклист «первичный осмотр базы» на 12 пунктов для L1.  
3. Отдельным блоком: какие права нужны пользователю 1С для подписи и отправки (гипотеза + что уточнить у админа).
