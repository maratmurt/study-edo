# Playbook — сертификат есть, закрытого ключа нет

## Симптомы

- Сертификат в «Личные», кнопка подписи неактивна / ошибка ключа  
- После переноса «бэкапа .cer» на новый ПК  

## Проверки

1. В свойствах сертификата есть ли указание на ключ?  
2. КриптоПро: контейнер связан с этим сертификатом?  
3. Токен вставлен? Тот ли считыватель?  
4. Контейнер в профиле **текущего** пользователя?  
5. Не импортирован ли только `.cer`/`.p7b`?  
6. Экспортировался ли ключ когда-либо (или запрет экспорта)?  

## Фиксы

- Вернуть носитель с контейнером  
- Установить сертификат **в контейнер** по инструкции УЦ  
- Перевыпуск, если ключ утрачен  
- Не путать копирование `.cer` с переносом ключа  

## Коммуникация пользователю

> Файл сертификата подтверждает личность открытого ключа, но подпись создаёт только закрытый ключ в контейнере. Без контейнера подписать нельзя — нужен токен/восстановление или перевыпуск.
