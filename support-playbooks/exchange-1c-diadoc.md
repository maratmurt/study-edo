# Playbook — обмен 1С ↔ Диадок

## Симптомы

- Документ не отправляется / завис в статусе  
- Нет входящих в 1С  
- Ошибка модуля при обмене  
- Контрагент не находится  

## Быстрые проверки (5 минут)

1. Текст ошибки дословно + скрин статуса ЭД в 1С.  
2. Есть ли документ в веб-кабинете Диадок?  
3. BoxId в 1С = BoxId в кабинете?  
4. Регламентное задание обмена: последний успешный запуск?  
5. Сертификат подписанта действителен? Есть МЧД?

## Ветвление

### A. В кабинете нет, в 1С «ошибка отправки»

- Класс: крипто / формат / API.  
- Смотреть лог отправки, код API, валидность XML.  

### B. В кабинете есть, в 1С нет

- Класс: интеграция.  
- Обмен, права, другая организация, фильтры журнала.  

### C. Контрагент не найден

- Приглашение, роуминг, КПП обособки, дубль ящиков.  

### D. Нет полномочий

- МЧД, срок, соответствие ИНН, кто выбран подписантом.  

## Эскалация

| Куда | Когда |
|------|--------|
| Админ 1С | Права, регламент, версии |
| Оператор Диадок | Роуминг, id ящика, транспорт |
| УЦ / крипто-админ | Ключ, контейнер |
| Разработка | Баг модуля, доработки |

## Вложения

BoxId, id документа, версии модуля/платформы, текст ошибки, скрин статуса в вебе и 1С.
