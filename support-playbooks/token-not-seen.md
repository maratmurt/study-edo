# Playbook — не видит токен

## Симптомы

- Нет считывателя в CSP  
- Ошибка носителя при подписи  
- В RDP «пусто», локально работало  

## Чеклист (15)

1. Токен физически вставлен  
2. Другой USB-порт / без «мертвого» хаба  
3. Индикатор токена / ОС видит устройство  
4. Установлен **родной** драйвер  
5. Переустановлен драйвер после major-обновления Windows  
6. Токен виден в утилите производителя  
7. КриптоПро видит считыватель  
8. Контейнер на этом токене (не в реестре другого ПК)  
9. PIN не заблокирован  
10. Правильный пользователь Windows  
11. Нет конфликта второго CSP  
12. Антивирус не блокирует  
13. Если RDP: где физически токен? включён ли проброс смарт-карт?  
14. Подпись должна быть на клиенте или на сервере по архитектуре?  
15. Тест на локальной сессии без RDP  

## Эскалация

Инфраструктура (RDP/GPO) · производитель токена · крипто-админ.
