# Playbook — КриптоПро Browser Plugin

## Симптомы

- Страница пишет, что плагин не найден  
- Бесконечная загрузка при подписи  
- Список сертификатов пуст  
- Работает в одном браузере, не в другом  

## Порядок установки (напоминание)

1. CSP  
2. ЭЦП Browser plug-in (native)  
3. Расширение браузера  
4. Перезапуск браузера  
5. Проверка на тестовой странице  

## Диагностика

1. Расширение включено? Не Incognito?  
2. Версии CSP / plug-in / расширения (паспорт).  
3. Консоль браузера: текст ошибки.  
4. HTTPS?  
5. Сертификаты видны в CSP вне браузера?  
6. Конфликт второго криптопровайдера?  
7. Корп. политики блокируют расширение?  

## Фиксы

- Доустановить недостающий компонент  
- Синхронизировать версии по матрице вендора  
- Проверить под тем же пользователем Windows, где контейнер  
- Исключить антивирус false-positive на native host (осознанно, временно)  

## Эскалация

L2 крипто / вендор, если тестовая страница вендора тоже падает при корректных версиях.
