# Шпаргалка — поля сертификата для поддержки

| Поле | Вопрос саппорта |
|------|-----------------|
| Subject CN / SN | Кто подписант? |
| O / INN / OGRN | Какая организация в сертификате? |
| Issuer | Какой УЦ? Стоит ли промежуточный? |
| Valid to | Не истёк? |
| Thumbprint | Какой именно серт выбран в 1С? |
| Key algorithm | ГОСТ или RSA? |
| EKU / Key usage | Разрешена ли подпись документов? |
| CDP / AIA | Откуда отзыв и цепочка? |

## Быстрый вердикт

1. Срок OK?  
2. Цепочка OK?  
3. Не отозван?  
4. Есть контейнер закрытого ключа?  
5. Полномочия / МЧД OK?
