# Шпаргалка — форматы подписи

## Attached vs detached

| | Attached | Detached |
|--|----------|----------|
| Данные в CMS | Да | Нет |
| Файлы | Один | Документ + `.sig`/`.p7s` |
| Риск | Тяжелее просмотр «как есть» | Легко потерять один из файлов |

## CAdES (кратко)

| Профиль | Суть |
|---------|------|
| BES | Базовая |
| T | + метка времени |
| XLT1 / Long-Term | + доказательства для долгого хранения |

## Частые расширения

`.sig`, `.p7s`, `.sgn`, иногда `.p7m` (encrypted/enveloped — не путать).

## Ломает проверку

- правка XML после подписи;  
- смена кодировки/BOM;  
- проверка не тем алгоритмом;  
- нет исходника при detached.
