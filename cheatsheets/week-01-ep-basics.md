# Шпаргалка недели 1 — основы ЭП

## ЭДО vs ЭП

- **ЭДО** — процесс и канал обмена электронными документами.  
- **ЭП** — реквизит авторства/целостности.  

## Виды ЭП

| Вид | Когда достаточно |
|-----|------------------|
| ПЭП | Соглашение сторон, личные кабинеты |
| НЭП | Соглашение / внутренний регламент + крипто |
| КЭП | По умолчанию = собственноручная; УПД, внешний ЮЗЭД |

## Цепочка

`данные → хеш (34.11) → подпись закрытым ключом (34.10) → сертификат + проверка цепочки/отзыва`

## Памятка саппорта

- Сертификат ≠ закрытый ключ  
- Detached = нужны данные + `.sig`  
- Истёк / отозван / нет промежуточного УЦ → «невалидна»  
- Несколько CSP на ПК — риск конфликтов
