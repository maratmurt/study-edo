# Шпаргалка недели 2 — Диадок и 1С

## Сущности Диадок

- Организация → **ящик (BoxId)**  
- Контрагент ← приглашение / роуминг  
- Документ / сообщение → статусы + подписи  

## Классы сбоев

1. Криптография  
2. Идентификация ЭДО (ящик, приглашение, роуминг)  
3. Полномочия (МЧД)  
4. Формат / реквизиты  
5. Интеграция (1С, API, регламент)  
6. Сеть  

## Осмотр 1С (коротко)

- [ ] Учётная запись ЭДО  
- [ ] BoxId = кабинет  
- [ ] Сертификаты и способ подписи (клиент/сервер)  
- [ ] Регламентные задания  
- [ ] Журнал ЭД / ошибка текстом  
- [ ] Версия модуля / библиотеки  

## Что логировать

`BoxId`, id документа/сообщения, этап (auth/sign/send/events), код+текст ошибки API, версия модуля.
