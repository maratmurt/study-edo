## Быстрые проверки

1. Расширение включено (не Incognito без разрешения)  
2. `cadesplugin` инициализируется  
3. HTTPS / localhost  
4. Сертификат + контейнер у текущего пользователя Windows  
5. Токен вставлен / PIN не блокирован  
6. Совместимость версий CSP↔плагин  

## Detached

На сервер: **исходные байты + Base64 подписи**. Не перекодировать данные после подписи.

## ГОСТ vs RSA

Проверяющий инструмент должен поддерживать алгоритм подписанта. Поля сертификата / OID подтверждают ГОСТ.
