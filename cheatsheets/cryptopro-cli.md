# Шпаргалка — КриптоПро CLI и GUI

> Синтаксис `cryptcp` зависит от версии. Перед боем проверяйте `cryptcp -help` / документацию вашей версии.

## GUI (часто достаточно для обучения)

- Панель **КриптоПро CSP** → Сервис: контейнеры, тест, копирование  
- Контекстное меню файла (если установлено): подписать / проверить  
- `certmgr.msc` — сертификаты пользователя  

## Типовые задачи

| Задача | Куда смотреть |
|--------|----------------|
| Список контейнеров | CSP → Сервис → Удалить/скопировать/просмотреть |
| Тест ключа | «Протестировать» контейнер |
| Установка сертификата в контейнер | Сервис → Установить личный сертификат |
| Просмотр цепочки | Свойства сертификата → Путь сертификации |

## cryptcp (ориентиры)

Часто встречаются режимы вида:

```text
cryptcp -signf -der -strict -cert -detached <file>
cryptcp -verify -detached <file> <file.sig>
```

Уточняйте ключи в help: имена параметров менялись между релизами.

## certutil (Windows)

```text
certutil -dump certificate.cer
certutil -verify -urlfetch certificate.cer
```

## Не делать

- Не присылать контейнер и PIN в тикетах  
- Не путать экспорт `.cer` с переносом ключа
