# Учебный курс: ЭП, ЭДО, Диадок, поддержка

4-недельный курс (теория + практика каждый день) для освоения российской электронной подписи, ЭДО через Диадок, связки с 1С, браузерной подписи и типовой техподдержки.

## Цели

После курса вы сможете:

- объяснить разницу ПЭП / НЭП / КЭП и цепочку «ключ → сертификат → подпись → проверка»;
- ориентироваться в ГОСТ-криптографии и стеке КриптоПро (CSP, контейнеры, носители);
- провести обмен документом в Диадок и локализовать сбой (1С / оператор / сертификат / контрагент);
- поднять и отладить подпись в браузере (плагин → CSP → носитель);
- вести диагностику по симптомам и вести сопровождение (обновления, истечение сертификатов).

## Как учиться

**Ритм дня (1,5–2,5 ч):**

1. Теория из файла дня — 40–60 мин  
2. Практика по шагам — 60–90 мин  
3. Конспект в `journal/` — 5–10 мин  

**Теория в проекте.** Каждый `curriculum/week-0N/day-NN.md` самодостаточен. Внешние ссылки — первоисточники и доки вендоров (установщики, API), не основной учебник.

**Если нет стенда** (тестовый Диадок, 1С, лицензия КриптоПро): выполняйте «лабораторию на бумаге» — схемы, разбор логов, playbook’и. В днях это отмечено отдельно.

## Критерии готовности дня

- [ ] Прочитана теория файла дня  
- [ ] Выполнена практика (или бумажный вариант)  
- [ ] Отмечен чеклист «Готово» в конце дня  
- [ ] Заполнена запись в `journal/`  

## Стек практики

- ОС: Windows  
- КриптоПро CSP + Browser Plugin  
- Оператор ЭДО: Диадок  
- 1С: библиотека ЭДО / модуль обмена с Диадок (демо или рабочая база)  

## С чего начать

1. Скопируйте [`journal/TEMPLATE.md`](journal/TEMPLATE.md) в `journal/day-01.md`.  
2. Откройте [`curriculum/week-01/day-01.md`](curriculum/week-01/day-01.md).  
3. Идите по дням подряд; ретроспективы (дни 7, 14, 21, 28) закрепляют неделю.
